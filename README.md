# 日期匹配信息提取工具

## 项目简介

这是一个专门用于从Word文档中提取日期匹配信息的Python工具。该工具能够自动识别文档中的主日期及其下属的四种匹配类型，并生成结构化的JSON数据，适用于提示系统或前端应用。

## 功能特点

### 🎯 核心功能
- **自动识别主日期**：识别包含"相关生日如下"的日期标题
- **四种匹配分类**：情人伴侣、工作伙伴朋友、竞争对手天敌、灵魂伴侣
- **智能文本处理**：自动清理全角空格、NBSP等特殊字符
- **数据验证**：验证日期格式的有效性

### 📊 输出格式
- **JSON格式**：主要数据结构，便于程序调用
- **反向索引**：支持按任意日期查询其匹配关系
- **Markdown表格**：便于文档展示
- **CSV文件**：便于Excel等工具处理
- **统计信息**：详细的匹配统计和分析

### 🔧 技术特性
- 健壮的错误处理
- 详细的调试信息
- 多种输出格式支持
- 完整的统计功能

## 开发说明

### 核心类：DateExtractor

#### 主要方法
- `extract_dates()`: 提取所有日期匹配信息
- `is_main_date_title()`: 识别主日期标题
- `is_category_title()`: 识别分类标题
- `extract_dates_from_text()`: 从文本中提取日期
- `generate_reverse_index()`: 生成反向索引
- `clean_text()`: 清理文本中的特殊字符

#### 文本处理
脚本会自动处理以下特殊字符：
- 全角空格（　）
- 不间断空格（\xa0）
- 普通空格（ ）

#### 正则表达式
- 主日期匹配：`r'^(\d{1,2}月\d{1,2}日)\s*相关生日如下[：:]*'`
- 日期提取：`r'\d{1,2}月\d{1,2}日'`

## 扩展功能

### 1. 反查功能
使用反向索引可以快速查询任意日期在哪些主日期中出现：
```python
with open('reverse_index.json', 'r', encoding='utf-8') as f:
    reverse_index = json.load(f)
    
# 查询某个日期的匹配情况
date = "1月9日"
if date in reverse_index:
    matches = reverse_index[date]
    print(f"{date} 在以下主日期中出现：")
    for match in matches:
        print(f"  {match['主日期']} - {match['分类']}")
```
